## Como visualizar

### Opção 1 — Online (mais fácil)
1. Acesse [plantuml.com/plantuml/uml](https://www.plantuml.com/plantuml/uml)
2. Cole o conteúdo do arquivo `.puml`
3. O diagrama é gerado automaticamente

### Opção 2 — VS Code
1. Instale a extensão **PlantUML** (jebbs.plantuml)
2. Abra o arquivo `.puml`
3. Pressione `Alt+D` para visualizar

### Opção 3 — Overleaf (LaTeX)
Use o pacote `plantuml` ou exporte como PNG/SVG e inclua com `\includegraphics`.
