# AmazonTrackData — Documentação e Trabalhos

Branch dedicada apenas à documentação e aos trabalhos acadêmicos do sistema AmazonTrackData.
O código do aplicativo fica nas branches `main`, `develop` e `release`.

| Pasta | Conteúdo |
|---|---|
| `01_Requisitos/` | Documento de Requisitos do Sistema (v1.0) — baseline para desenvolvimento, validação e aceite |
| `02_Arquitetura_de_Software/` | Documento de Arquitetura de Software da Linha de Produtos AmazonTrack (ISO/IEC/IEEE 42010) |
| `03_Qualidade_de_Software_GQS/` | Projeto Final de Gestão da Qualidade de Software |
| `04_Gerencia_de_Configuracao_DevOps/` | Plano de Gerenciamento de Configuração (PGC) e roteiro da apresentação |
| `05_Teste_Verificacao_Validacao/` | Trabalho 1: Plano de Testes (PT-ATD-001) · Trabalho 2: Análise e Projeto de Testes (EAPT-ATD-001) · Trabalho 3: Relatório de Resumo de Testes (RRT-ATD-001), com a suíte de testes (`suite/`) e as saídas da execução (`resultados/`) |
| `06_Sistemas_Distribuidos_Artigo_DTN/` | Artigo sobre monitoramento fluvial baseado em redes DTN (PDF final, fonte LaTeX e relatório técnico) |
| `07_PIBITI/` | Relatório Final PIBITI 2025–2026 |
| `08_Eventos/` | CONIC 35 (resumo expandido e apresentação oral) · SACI 2026 (resumo e apresentação) |
| `09_Documentacao_Tecnica/` | Guias de configuração (projeto, Firebase, plataformas), regras do Firestore/Storage e diagramas UML (PlantUML) |

## Observações

- A suíte em `05_.../Trabalho3_.../suite/` é executada a partir do código do aplicativo (ver `suite/README.md`).
- Templates, enunciados, versões antigas e scripts de geração dos documentos não fazem parte desta branch.
